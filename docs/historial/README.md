# Material histórico

`diferencias.txt` es un informe de diferencias Git que ya existía en
`enfe-red/diferencias.txt`. Se conserva aquí como referencia histórica, sin
modificar su contenido. Sus rutas y estadísticas no representan necesariamente
la estructura actual; algunas mencionan el frontend duplicado que fue retirado.

Para trabajar con la aplicación usar el [README general](../../README.md).
